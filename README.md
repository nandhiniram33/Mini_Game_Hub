# 🎮 Mini Game Hub

A fun and interactive **browser-based mini game arcade** built using **HTML, CSS, and JavaScript**. Play multiple games, earn XP and coins, unlock achievements, complete daily challenges, and compete on the leaderboard.

## 🚀 Features

* 🎮 **Three Mini Games**

  * ✊ Rock Paper Scissors
  * 🔢 Number Guessing
  * ❌⭕ Tic-Tac-Toe

* ⭐ **Level & XP System**

  * Earn XP by playing games and completing challenges.
  * Level up as your XP increases.

* 🪙 **Coin Reward System**

  * Earn coins from games and daily rewards.
  * Spend coins to unlock cosmetic themes.

* 🎯 **Daily Challenges**

  * Complete different daily objectives.
  * Earn bonus XP and coins.

* 🏅 **Achievements**

  * Unlock achievements for winning games, maintaining streaks, and completing special challenges.

* 🏆 **Leaderboard**

  * Track player scores, levels, and rankings.

* 📊 **Game Statistics**

  * Games played
  * Wins
  * Losses
  * Draws
  * Win rate
  * Best streak
  * Total XP

* 👤 **Player Profile**

  * Customize username.
  * Select an avatar.
  * Choose your favorite game.

* 🛍️ **Reward Shop**

  * Unlock different cosmetic themes using earned coins.

* 🌙 **Dark & Light Mode**

  * Switch between dark and light themes.

* 🔊 **Sound Effects**

  * Enable or disable game sounds.

* 💾 **Local Storage**

  * Player progress, settings, rewards, and game statistics are saved in the browser.

## 🛠️ Technologies Used

* **HTML5** – Structure and layout
* **CSS3** – Styling, responsive UI, animations, and themes
* **JavaScript** – Game logic, player progression, statistics, and local storage

## 🎯 How to Play

1. Open `index.html` in your browser.
2. Enter your username.
3. Choose any game from the Game Arcade.
4. Play and earn XP and coins.
5. Complete daily challenges.
6. Unlock achievements and cosmetic themes.
7. Check your statistics and leaderboard ranking.

## 🎮 Game Modes

### ✊ Rock Paper Scissors

Play against the computer by choosing Rock, Paper, or Scissors.

### 🔢 Number Guessing

Try to guess the hidden number using hints and a limited number of attempts. The game supports **Easy, Medium, and Hard** difficulty levels.

### ❌⭕ Tic-Tac-Toe

Challenge the computer in a classic Tic-Tac-Toe match with multiple difficulty levels.
